## Filosofía de Datos y Arquitectura (CRÍTICO)

La aplicación es una **INTRANET local**, no una Extranet.
- Funciona exclusivamente dentro de la red del instituto.
- Los datos sensibles (SGC, alumnado, orientación, documentos internos) se almacenan en una base de datos local (SQLite).
- **No se expone a internet** por motivos de máxima seguridad y privacidad.

## Estructura de Datos
1. **Documentos Oficiales (PDFs)**: PEC, RRI, PGA, etc. Estáticos, almacenados localmente.
2. **Datos del SGC y Orientación**: Almacenados en base de datos.
3. **Flujo de Migración**: Progresivamente, los datos que actualmente residen en Google Sheets / Forms de la organización escolar se están migrando al sistema de base de datos local para tener un control y trazabilidad 100% offline dentro de la red local.

## Stack Tecnológico

- **Frontend**: Next.js, React, Tailwind CSS.
- **Backend**: Python, FastAPI.
- **Base de Datos**: SQLite local.
